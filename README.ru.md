# NoSleep

NoSleep — лёгкая утилита, не дающая Windows автоматически включать заставку, спящий режим или экран блокировки. Она создана для ситуаций, когда вы не можете изменить эти настройки самостоятельно — например, из-за корпоративных политик. Вдохновлена Linux-утилитой Caffeine.

> **Примечание:** в Windows PowerToys есть аналогичный инструмент Awake, но PowerToys может требовать прав администратора и довольно велик. NoSleep стремится быть максимально компактной и работает без дополнительных разрешений.

## Установка

NoSleep можно установить через менеджер пакетов [Scoop](https://scoop.sh/):

```sh
scoop bucket add extras
scoop install extras/nosleep
```

Либо скачайте последний релиз вручную со [страницы релизов](https://github.com/CHerSun/NoSleep/releases/latest). Релиз содержит три исполняемых файла:

- **`NoSleep.exe`** — основная сборка для всех (работает на .NET Framework 4.8, предустановленном в Windows).
- **`NoSleep-net8.exe`** / **`NoSleep-net10.exe`** — однофайловые сборки для пользователей, у которых уже установлена среда .NET 8 или .NET 10.

## Использование

NoSleep создана по принципу «настроил и забыл». Запущенная программа сидит в системном трее и не даёт компьютеру уснуть.

- **Левый клик** по значку в трею включает или выключает программу. Значок меняется в зависимости от состояния.
- **Правый клик** по значку открывает меню с дополнительными опциями:

  - **Автозапуск при входе** — запускать NoSleep автоматически при входе в систему.
  - **Держать экран включённым** — не давать дисплею выключаться, пока NoSleep включён.
  - **Запоминать состояние** — сохранять состояние включения между перезапусками программы.
  - **Настроить отслеживаемые программы** — задать список приложений. Если ни одно из них не запущено, NoSleep автоматически отключает себя; если запущено хотя бы одно — включает и препятствует засыпанию. Это динамическое поведение работает только когда NoSleep включён пользователем. (Доступно с v1.4.0)

Чтобы полностью остановить NoSleep, кликните правой кнопкой по значку в трее и выберите **Закрыть**.

### Язык

Интерфейс автоматически следует языку отображения Windows среди **English, Русский и 简体中文**. Чтобы выбрать язык явно, запускайте с флагом `--lang`:

```sh
NoSleep.exe --lang ru        # русский для этого запуска
NoSleep.exe --lang zh-CN     # упрощённый китайский
NoSleep.exe --lang list      # показать доступные языки
```

Чтобы сделать выбор постоянным, добавьте флаг в поле «Объект» ярлыка NoSleep.

## Требования

- **`NoSleep.exe`** (основная сборка): .NET Framework 4.8 или новее — как правило, предустановлен в Windows 10 и новее; при необходимости скачивается с [сайта Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet-framework).
- **`NoSleep-net8.exe`** / **`NoSleep-net10.exe`**: соответствующая среда .NET.

## Как это работает

NoSleep вызывает функцию `SetThreadExecutionState` каждые 10 секунд, сбрасывая таймеры дисплея и простоя Windows. Процесс практически не нагружает CPU и использует немного оперативной памяти. В скомпилированный файл входят иконки (около 180 КБ) и код программы.
